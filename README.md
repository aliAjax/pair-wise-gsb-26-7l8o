# hxwl-12 心理测评与复测跟踪台

个案按量表版本录入条目，按正反向计分生成总分与风险等级，并跟踪复测窗口、升级联系计划与版本更正。

## 技术栈

React 19 + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112；`npm run build` 可做生产构建与类型检查。

## 分层结构

| 层 | 路径 | 职责 |
| --- | --- | --- |
| 领域数据 | `src/domain/types.ts`、`src/domain/scales.ts` | 个案/测评/计划数据模型；量表版本（PHQ-9、GAD-7、RSES 2024 版）的条目、正反向标记、分段阈值 |
| 计算规则 | `src/domain/rules.ts` | 纯函数：正反向计分、分项分、总分、风险等级、7 天复测闸门、升级/高风险闸门、冻结更正冲突、复测提醒 |
| 状态 | `src/state/store.ts` | 装配规则结果、localStorage 持久化、跨标签页 `storage` 同步、审计日志 |
| 界面 | `src/ui/*` | 跟踪台、录入台、个案档案、联系计划、规则中心 |

## 业务规则

- **R-SCORE 按版本计分**：正向条目计录入值；反向条目按 `最小值+最大值−录入值` 翻转；缺条目整单拒绝。
- **R-GATE 升级/高风险闸门**：风险等级 rank 严格升高或达到高风险阈值时，必须同时登记联系计划内容、责任咨询师、完成时限，否则整单拒绝。
- **R-RETEST 复测间隔**：同一(个案,量表)距上次**有效**测评不足 7 天不能复测；拒绝时列出个案、量表、前次日期和剩余天数。
- **R-FREEZE 冻结更正**：已接受测评冻结；更正须填原因，生成新版本（seq+1），原条目、分项分、总分、风险等级全部保留为 `superseded`；更正不受 7 天限制，但仍走 R-GATE。
- **一致性**：刷新后个案、测评版本、联系计划、复测提醒均由同一份持久化数据经纯函数派生；冲突统一展示个案、量表、原值、新值与触发规则，全部写入「触发记录」。
